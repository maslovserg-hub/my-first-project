# Контроль нормативки

PWA-приложение для поиска по нормативной документации по **электроэнергетике** и **пожарной безопасности** голосом и текстом. Работает локально в браузере телефона.

## Что умеет

- **Два режима ввода:** «Нарушение» (наговорил, что увидел → находит нарушенный пункт) и «Вопрос» (задал вопрос → находит нужный фрагмент нормы).
- **Голосовой ввод** через Web Speech API (`ru-RU`).
- **Локальный поиск** по двум источникам:
  - **Встроенная база** — демо-выдержки из:
    - *Электроэнергетика:* ФЗ-35 «Об электроэнергетике», ПУЭ (7-е изд.), ПТЭЭП, ПОТЭЭ (Приказ Минтруда №903н), ГОСТ 32144-2013, СП 256.1325800.2016, ГОСТ Р 50571.3-2009.
    - *Пожарная безопасность:* ФЗ-123, ППР в РФ (ПП №1479), СП 1.13130.2020, СП 484.1311500.2020, СП 486.1311500.2020.
  - **Папка на телефоне** — подключается через File System Access API, парсит `.pdf` (через pdf.js), `.txt`, `.md`.
- **Кнопки внешнего поиска** — открывают запрос в Яндексе с фильтром по `cntd.ru` / `docs.cntd.ru`.
- **Готовая запись для акта** — на каждый найденный пункт формируется текст вида:
  `Нарушение п. X.Y СП Z: <твоё описание>. Требование: <цитата нормы>`.
- **История** — последние 10 запросов в `localStorage`, можно вернуться и переиспользовать.
- **Установка иконкой на главный экран** — PWA-манифест и service worker для оффлайн-работы.

⚠️ **Встроенная база — демонстрационная.** Формулировки и номера пунктов даны для проверки логики поиска. Для реальной работы загружай актуальные редакции документов в подключённую папку — нормативка по электрике и пожаркам регулярно обновляется (ПОТЭЭ-2020, СП 484/486 от 1 марта 2021 и т.д.).

## Как запустить

### На телефоне (Android Chrome — основной сценарий)

1. Открой страницу по `https://`-адресу (например, GitHub Pages — `file://` не даст PWA-функций и не пустит к папке).
2. В меню Chrome выбери «Добавить на главный экран» — иконка приложения появится как у обычного приложения.
3. Открывай иконкой, нажимай микрофон, говори.
4. Чтобы подключить свою папку с PDF — нажми «Подключить» рядом с «Папка на телефоне», выбери папку, дай разрешение. Файлы остаются на устройстве, ничего никуда не загружается.

**Пример тестовых запросов:**
- Электроэнергетика: «отсутствует заземление металлического корпуса электрощита» / «какое сопротивление изоляции в сети до 1000 В».
- Пожарная безопасность: «эвакуационная дверь открывается внутрь помещения» / «на каком расстоянии от очага должен быть огнетушитель».

### Локально (для проверки)

```bash
# Из корня репозитория:
python3 -m http.server 8000
# Открой http://localhost:8000/voice-compliance/
```

Прямое открытие `file://` тоже работает, но без выбора папки (File System Access API требует `https://` или `localhost`).

## Юридический момент

См. блок «Конфиденциальность» прямо в UI. Кратко:

- Файлы и текст в браузере **не уходят на сервер** — поиск чисто локальный.
- Голос идёт через распознавалку Google — **не произноси КТ, ФИО, номера договоров**, если есть такие ограничения.
- Кнопки «Искать в интернете» открывают внешний сайт — там работают правила того сайта.
- История запросов — только в `localStorage` этого браузера.

## Поддерживаемые форматы документов

- ✅ `.pdf` — через pdf.js
- ✅ `.txt`, `.md` — нативно
- ❌ `.docx`, `.doc`, `.rtf` — конвертируй в PDF перед загрузкой

## Ограничения

- **File System Access API** — только Chromium-браузеры (Chrome, Edge, Samsung Internet). На iOS Safari выбор папки **не работает** — там придётся выбирать файлы по одному (TODO: добавить такой fallback).
- **Web Speech API** — Chrome (Android и десктоп), Edge. На Firefox и iOS Safari распознавание речи отсутствует или работает нестабильно.
- **Морфология русского** — реализована упрощённо (обрезка окончаний). Для большинства строительных терминов работает; для редких форм может промахиваться.
- **Парсинг PDF** — извлекается только текст. PDF-сканы (изображения) без OCR не индексируются.
