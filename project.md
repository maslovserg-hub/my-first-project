# Проект: AI-сайт для помогающих специалистов

## Что это за проект

Личный сайт-экосистема Сергея Маслова, ориентированный на психологов, коучей и терапевтов. Лендинг демонстрирует ценность готового AI-сайта как инструмента продаж 24/7, а визитка служит цифровой точкой входа для быстрого знакомства с автором. Проект полностью статический — без бэкенда, на чистом HTML/CSS/JS.

## Для кого

**Целевая аудитория лендинга:** психологи, коучи, расстановщики, терапевты, нумерологи и другие помогающие специалисты, которым нужен сайт, продающий их услуги без их участия.

**Целевая аудитория визитки:** все, кому Сергей даёт свой контакт — визитка служит точкой входа и переводит на мессенджеры (Telegram, Max).

## Стиль дизайна

Проект использует **два визуальных языка**:

### Лендинг — «Тёмный космос» (применяется ко всем новым страницам по умолчанию)
- Фон: тёмно-синий/фиолетовый градиент (`#0a0a14`)
- Акценты: фиолетовый → синий → зелёный (`#7c3aed` → `#3b82f6` → `#10b981`)
- Градиентный текст: `#a78bfa` → `#60a5fa` → `#34d399`
- Типографика: системный sans-serif, fluid-размеры через `clamp()`
- Анимации: звёздный фон, fade-in карточек, пульсирующие кнопки
- Сетка: CSS Grid + Flexbox, контейнер до 960–1080px

### Визитка — «Тёмное золото» (только vizitka.html)
- Фон: очень тёмный коричневый (`#0a0a08`)
- Акценты: тёплое золото (`#c8a84b`, `#f0c060`, `#a07830`)
- Типографика: Cormorant Garamond (засечки, для имени) + Raleway (гротеск, для остального)
- Анимации: золотое свечение аватара, интерактивный блик имени следящий за курсором

### Общее
- Полностью адаптивный дизайн, включая отдельную логику для тач-устройств
- QR-коды: при наведении на десктопе, по тапу на мобильных
- Самописный генератор QR-кодов (встроен в JS, Reed-Solomon ECC, версии 1–7)
